# STAR//SQUARE

A browser bullet-hell game.

## Publish with GitHub Pages

1. Create a new public GitHub repository (for example, `star-square`).
2. Upload `index.html` from this folder to the repository root and commit it.
3. Open **Settings → Pages** in the repository. Select **Deploy from a branch**, choose `main` and `/ (root)`, then save.
4. After GitHub finishes building, the game will be available at `https://YOUR-USERNAME.github.io/REPOSITORY-NAME/`.

The standalone Pages build saves progress in the browser. The separate Node leaderboard server is not hosted by GitHub Pages.
